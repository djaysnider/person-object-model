# Contributing

Thank you for your interest in contributing to this project.

Before submitting an issue, pull request, employment offer, romantic overture, dinner invitation, or unsolicited recommendation for improving my life, please review the following guidelines.

## Supported Contribution Types

Contributions are generally welcome in the following areas:

```yaml
contributions:
  interesting_problems: strongly_encouraged
  new_ideas: encouraged
  constructive_disagreement: encouraged
  obscure_music: encouraged
  food: usually_accepted
  travel_opportunities: evaluated_case_by_case
  management: requires_prior_approval
  personal_advice: experimental
  lifestyle_restructuring: unsupported
```

## Employment Contributions

Before submitting an employment-related pull request, please verify that the proposed position:

```pseudo
IF problem_is_already_solved
    AND procedures_are_already_defined
    AND primary_expectation == "keep doing this forever"
THEN
    RETURN DECLINED

IF problem == "we don't entirely know what we need"
    AND authority >= responsibility
    AND management.accepts("I have an idea")
THEN
    RETURN INTERESTING
```

Please do not open an issue asking the maintainer to "think outside the box" if your organization maintains a fourteen-step approval process for modifying the box.

## Romantic Contributions

Romantic contributions remain supported but should be considered a **high-risk integration scenario**.

Prospective contributors should understand that the maintainer:

* maintains several concurrent hobbies;
* may become unexpectedly passionate about extremely specific subjects;
* considers "What are you thinking about?" a dangerous question;
* occasionally begins projects because existing solutions offended him;
* regards wandering around an unfamiliar city as an itinerary;
* may evaluate restaurants partly by whether he thinks he could make the entrée better himself;
* has strong opinions concerning music, fiction, technology, and cheese selection.

None of these behaviors are currently classified as bugs.

Feature requests will be reviewed but may be closed as `works-as-designed`.

## Known Compatibility Issues

The maintainer may exhibit degraded performance in environments involving:

```yaml
conditions:
  micromanagement: CRITICAL
  pointless_meetings: HIGH
  artificial_urgency: HIGH
  small_talk_over_45_minutes: MODERATE
  incurious_people: SEVERE
  "because we've always done it this way": FATAL
```

Exposure to interesting problems, intelligent disagreement, good food, strange music, bookstores, and sufficiently peculiar conversations has been shown to restore normal operation.

## Pull Requests

Before requesting a behavioral modification, please ask:

1. Is this actually a defect?
2. Is it merely something I would do differently?
3. Has this behavior existed successfully in production for several decades?
4. Am I absolutely certain I want to start this conversation?

If the answer to #4 is "yes," proceed.

You were warned.

## Breaking Changes

Breaking changes are occasionally introduced without notice following:

* major life events;
* unusually persuasive books;
* travel;
* encounters with better ideas;
* sufficient evidence that the maintainer was wrong.

Backward compatibility with opinions expressed more than ten years ago is **not guaranteed**.

## Forking

Forking is permitted.

However, attempts to create a simplified version with fewer interests, stronger adherence to convention, broader musical compatibility, or greater enthusiasm for repetitive work constitute a substantially different project and should probably be maintained separately.

## Support

This project is provided **AS IS**, without warranty of merchantability, fitness for a particular corporate culture, romantic compatibility, or willingness to attend a 4:30 PM Friday meeting.

Long-term support is nevertheless available to compatible users.

## Final Warning

If you have read this entire file before interviewing, hiring, dating, or otherwise engaging with the maintainer, congratulations:

You have successfully completed the first compatibility test.

Proceed at your own risk.
